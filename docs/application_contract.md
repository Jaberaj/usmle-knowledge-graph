# Application contract v1.0.0

Applications consume UTF-8 snake_case JSON in `dist/json`, not source table internals. `manifest.json` contains versions, counts, SHA-256 checksums, build metadata, compatibility notes, and disclaimer. `entities.json` and `relationships.json` expose normalized records. Disease, presentation, treatment, medication, algorithm, game, and search bundles are deterministic application-ready projections. Draft review status must be honored by clients.
