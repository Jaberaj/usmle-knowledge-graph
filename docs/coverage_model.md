# Coverage-first model

This repository prioritizes broad, internally consistent USMLE coverage over a
clinical-decision-support certification process. It is educational only and is
not patient-specific advice.

`source_status` describes support for the represented topic areas:
`unverified_ai_generated`, `partially_source_supported`, `source_supported`,
`conflicting_sources`, or `deprecated`. A general reference must not be read as
support for every field in an entity. `entity_references` identifies the topics
and locator that a source supports.

`human_review_status` is independent: `not_requested`, `optional_review`, or
`reviewed`. It does not control bundle inclusion or learning-game eligibility.

Coverage tiers are `index`, `core`, `expanded`, and `comprehensive`. Bundles
derive game eligibility from linked presentations, differentials, treatments,
algorithms, and explanatory keywords. Coverage reports make remaining gaps
visible rather than suppressing useful unverified educational records.
